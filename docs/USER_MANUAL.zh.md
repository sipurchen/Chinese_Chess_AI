## 一、安裝與啟動

### 系統需求

| 套件 | 版本 | 用途 |
|------|------|------|
| Python | 3.8+ | 執行環境 |
| Flask | 任意 | Web 伺服器 |
| Pillow | 任意 | 棋盤影像渲染（自對弈） |

### 安裝步驟

```bash
# 複製 Repo
git clone https://github.com/sipurchen/Chinese_Chess_AI.git
cd Chinese_Chess_AI

# 安裝相依套件
pip install flask pillow

# 啟動伺服器
python app.py
```

在瀏覽器開啟：**http://localhost:5000**

> **注意：** 伺服器預設綁定 `0.0.0.0:5000`。在終端機按 `Ctrl+C` 可停止。

## 二、模式一 — 人機對弈

這是開啟 App 後的預設模式。

### 2.1 選擇難度

點擊左側面板中的其中一個按鈕：

| 按鈕 | AI 個性 | 強度 |
|------|---------|------|
| **初學者** | 初學者 | 簡單 — 深度 1，有隨機變化 |
| **柳大華** | 柳大華 | 中等 — 深度 3，戰術型 / 積極進攻 |
| **胡榮華** | 胡榮華 | 困難 — 深度 4，陣地型 / 殘局精確 |

難度可隨時切換，無需重置棋盤。

### 2.2 下棋操作

1. **點擊**任意己方棋子（紅方先走）
2. 棋子以綠色高亮顯示；合法目標格以圓點標示
3. **點擊**任意合法目標格完成走棋
4. AI 立即計算並走出應對

### 2.3 解讀 AI 思考面板

每次 AI 走棋後，右側面板顯示：

| 欄位 | 含義 |
|------|------|
| **分數** | 盤面評估（正值 = 紅方優勢） |
| **幾步殺** | 若有設定，代表已找到 N 步強殺 |
| **開局** | 仍在開局書中時顯示開局名（如 當頭炮） |
| **來源** | `opening_book`（開局書）或 `search`（搜索） |
| **先手** | 哪方擁有更快的強殺威脅 |

### 2.4 控制按鈕

- **重置** — 回到開局初始盤面
- **悔棋** — 尚未實作（規劃於第二階段加入）

## 三、模式二 — AI 對弈（循環賽）

觀看三名 AI 個性進行循環賽。

### 3.1 開始賽事

1. 點擊 **AI 對弈** 分頁
2. 設定每對棋手的局數（預設 10 局；建議最多 50 局）
3. 點擊 **開始賽事**

賽事在背景執行緒中運行，不影響其他頁面操作。

### 3.2 解讀積分表

| 欄位 | 含義 |
|------|------|
| **棋手** | AI 個性名稱 |
| **勝 W** | 勝場數 |
| **負 L** | 敗場數 |
| **和 D** | 和局數 |
| **點** | 積分（勝=2，和=1，負=0） |

積分表透過輪詢即時更新。

### 3.3 回放棋局

1. 從場次下拉選單選取已完成的場次
2. 選擇指定的棋局檔案
3. 點擊 **載入回放**
4. 使用 **◀ ▶** 按鈕逐步瀏覽
5. 在任意局面點擊 **分析** 取得 AI 評估

---

## 四、模式三 — 分析棋局

逐步分析任意已儲存的棋譜。

### 4.1 載入棋局

1. 點擊 **分析棋局** 分頁
2. 從 **棋譜檔案** 下拉選單選取（列出 `AI_Games/` 下所有檔案）
3. 點擊 **載入**

### 4.2 瀏覽著法

| 按鈕 | 動作 |
|------|------|
| **◀◀** | 跳至開始 |
| **◀** | 上一步 |
| **▶** | 下一步 |
| **▶▶** | 跳至結束 |

棋盤隨著每步更新；最後一步以黃色高亮顯示。

### 4.3 請求 AI 分析

在任意局面點擊 **AI 分析**。引擎評估當前盤面並顯示：
- 分數與幾步殺（若有）
- 當前局面所屬開局
- 先手態勢評估

---

## 五、模式四 — 試解殘局

擺出任意局面，讓 AI 求解，或探索內建殘局題庫。

### 5.1 擺設局面

1. 點擊 **試解殘局** 分頁
2. 棋盤下方出現**棋子調色盤**
3. **左鍵點擊**調色盤中的棋子以選中（高亮顯示）
4. **左鍵點擊**棋盤格子以放置棋子
5. **右鍵點擊**棋盤上的棋子以移除

> **提示：** 棋盤初始為空。也可右鍵點擊所有棋子清空重來。

### 5.2 AI 求解

1. 選擇行棋方（**紅先** / **黑先**）
2. 點擊 **AI 求解**
3. AI 搜索最佳序列並顯示：
   - 最佳首步
   - 分數 / 幾步殺
   - 主要變例（著法序列）

### 5.3 內建題庫

點擊 **載入題庫** 瀏覽 5 道內建殘局。點擊任意題目將其載入棋盤，再點擊 **AI 求解** 驗證解答。

### 5.4 尋找相似殘局

擺好局面後，點擊 **相似殘局**，搜索題庫中棋子構成相似的題目（Sørensen-Dice 相似度 ≥ 0.5）。

### 5.5 儲存殘局

1. 擺好局面
2. 填入 **題目名稱** 和 **解答說明**
3. 點擊 **儲存殘局**

儲存的題目存於 `AI_Games/endgame_puzzles.json`，之後可在 **載入題庫** 中找到。

## 六、自對弈模擬（self_play.py）

產生 AI 對 AI 的棋局記錄與棋盤截圖。

```bash
python self_play.py
```

運行三場比賽：
- 初學者 vs 主引擎
- 柳大華 vs 主引擎
- 胡榮華 vs 主引擎

輸出儲存至 `AI_Games/<棋手>/`：

| 檔案 | 內容 |
|------|------|
| `game_record_<時間戳>.txt` | 逐步文字記錄（含分數） |
| `game_record_<時間戳>.json` | 機器可讀格式（含轉折點索引） |
| `<時間戳>_turn_XXX_TurningPoint.png` | 關鍵時刻棋盤截圖 |

滿足以下任一條件即截圖：
- 分差超過 40 分
- 偵測到強殺（≤ 5 步）
- 先手優勢翻轉
- 重子（俥）被吃

## 八、常見問題排除

| 問題 | 原因 | 解法 |
|------|------|------|
| 棋盤無反應 | JS 錯誤 | 開啟瀏覽器 DevTools → Console；重新整理 |
| AI 計算極慢 | 搜索深度過高 | 切換至初學者或柳大華 |
| 5000 埠被占用 | 其他程序占用 | 改用其他埠：`python app.py --port 5001` |
| PNG 中文字亂碼 | 缺少 CJK 字體 | 在作業系統安裝 SimSun / Noto CJK |
| 賽事無法啟動 | 前一場仍在執行 | 重新整理頁面以終止舊執行緒 |
